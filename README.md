# Hayki

Hayki is a clothing store management and e-commerce system developed to support product management, inventory management, customer orders, transactions, payments, and promotions.

## Features

### Buyer
- Browse products
- View product details
- View product variants
- Add products to cart
- Manage cart
- Checkout
- Create orders
- View order history
- Upload payment proof
- Online payment

### Employee
- Manage products
- Upload product images
- Manage product variants
- Manage stock
- Manage customer orders
- Manage cashier transactions
- View transaction history
- Submit promotions

### Management
- View dashboard information
- Monitor transactions
- Monitor stock
- View sales reports
- View transaction history
- Manage promotions

## REST API

Hayki provides REST API endpoints for management features such as:

- Authentication
- Dashboard
- Transactions
- Stock
- Reports
- Transaction history
- Promotions

API authentication is implemented using Laravel Sanctum.
